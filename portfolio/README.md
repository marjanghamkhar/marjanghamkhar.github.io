# Marjan Ghamkhar — Selected Works

A responsive web version of the original nine-page **Selected Works** PDF.

- **Exact source visuals**: the Vora, Breathe, and CAMVVA collages are exported directly from the original PDF. No replacement stock art or invented interface screens.
- **Exact project content**: text transcribed from the portfolio's Challenges, Solutions, and Design Outcomes pages.
- **Website enhancements**: responsive layouts, clickable contents, anchor navigation, subtle IntersectionObserver transitions, reduced-motion support, keyboard access, and a scroll progress indicator.
- **Hosting**: static HTML, CSS and JS, intended for `/portfolio/` on a GitHub Pages user repository.

## Publish

Upload the contents of this folder to a `portfolio` directory in the `marjanghamkhar.github.io` repository. For a working URL of `https://marjanghamkhar.github.io/portfolio/`, the entry document must be at `portfolio/index.html`.

The original PDF also contains a phone number on the final page. This website intentionally publishes the email address only, to avoid unintentionally publishing an extra private contact detail. This can be changed on request.
