# Marjan Ghamkhar — Selected Builds

A minimal, accessible showcase of two interactive product-design projects:

- [Orbit — Focus Space](https://marjanghamkhar.github.io/orbit-focus-space/)
- [Signal — Feedback Prioritizer](https://marjanghamkhar.github.io/signal-feedback-prioritizer/)

## About

Designed and directed by Marjan Ghamkhar, with AI-assisted development. Built as a lightweight static website using HTML, CSS, and a few lines of JavaScript. The project cards contain **illustrative interface previews**, not live user data.

## Deploy with GitHub Pages

1. Create a **public** GitHub repository called `marjanghamkhar.github.io` under GitHub user `marjanghamkhar`.
2. Upload **the contents of this folder** to the repository root (the GitHub website upload interface does not accept ZIP files as an extracted site).
3. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, directory `/(root)`, and save.
4. The site should be available at `https://marjanghamkhar.github.io/` when Pages finishes publishing.

No build process, Node installation, or third-party packages are needed.
